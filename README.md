# Conversor de Moedas

Aplicação web simples para conversão de valores entre diferentes moedas, com cotações obtidas em tempo real.

## Funcionalidades

- Conversão de valores entre moedas
- Consulta de cotações atualizadas via API externa
- Interface simples e responsiva

## Tecnologias utilizadas

- JavaScript
- HTML5
- CSS3
- AwesomeAPI — API pública de cotações de moedas

## Como rodar localmente

1. Clone o repositório
   ```bash
   git clone https://github.com/WalneyLinhares/conversor-moedas.git
   cd conversor-moedas
   ```

2. Abra o arquivo `index.html` diretamente no navegador

   Ou, se preferir usar um servidor local (recomendado para evitar bloqueios de CORS):
   ```bash
   npx serve .
   ```

3. Acesse a aplicação no navegador e escolha as moedas e o valor a converter
